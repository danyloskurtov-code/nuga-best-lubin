# Nuga Best Lubin — strona salon

Одностраничный сайт салона Nuga Best в Любине (ul. Stefana Kisielewskiego 22).

## Структура

```
index.html        — весь сайт (HTML + стили в одном файле)
zdjecia/          — папка для фотографий
  hero.jpg        — фон главного экрана
  zespol.jpg      — фото команды
```

## Что заменить перед публикацией

Открыть `index.html`, найти через Ctrl+F и заменить:

| Плейсхолдер | Что вставить |
|---|---|
| `{{LINK_KALENDARZ}}` | ссылка записи Google Calendar |
| `{{LINK_GOOGLE}}` | ссылка на профиль Google (отзывы) |
| `{{LINK_MAPA}}` | ссылка «Wyznacz trasę» из Google Maps |
| `{{LINK_GALERIA}}` | ссылка на фотоальбом |
| `{{LINK_URZADZENIA}}` | https://www.nugabestpolska.pl (страница устройств) |
| `{{OCENA}}` | средняя оценка в Google, напр. 4,9 |
| `{{ILE_OPINII}}` | количество отзывов, напр. 87 |
| `{{OPINIA_1..3}}`, `{{AUTOR_1..3}}` | 3 цитаты из Google-отзывов — ТОЛЬКО про сервис/атмосферу |
| `{{IMIE_1..3}}` | имена команды |

Телефон, адрес и часы работы уже вставлены.
